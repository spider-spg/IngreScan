# IngreScan - Personalized Food Ingredient Scanner

**Your personalized food companion for healthier choices** 🍎

IngreScan is a React Native mobile application built with Expo that helps users make informed food choices by scanning product barcodes and providing personalized health insights based on individual health conditions, dietary preferences, and allergens.

```
ingrescan/
├── server/
│   └── score_api.py
├── scoring_engine.py
├── package.json
├── App.js
└── src/
    └── ...
```

Run:

```powershell
python server\score_api.py
npx expo start
```
